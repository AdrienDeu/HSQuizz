# Language Consistency Spec Delta

## MODIFIED Requirements

### Requirement: Standardize UI text to English
The application's user interface text MUST be consistently in English to align with the language of the card data, providing a unified user experience.
#### Scenario: All UI text should be consistently in English
Given the card data is in English, the user interface should primarily be in English to ensure a consistent experience. This includes all labels, button texts, instructions, and messages displayed to the user.

#### Scenario: French strings in the UI should be translated to English
Any existing French text elements in the user interface (e.g., "inclure les éléments non collectibles") should be identified and translated into their English equivalents (e.g., "Include uncollectible items").
