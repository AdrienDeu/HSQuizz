To test the responsive navbar:

1.  **Run the frontend application:**
    Navigate to the `frontend` directory in your terminal and run the command to start the Angular development server (e.g., `npm start` or `ng serve`).

2.  **Open in Browser:**
    Open your web browser and navigate to the address where the frontend application is running (usually `http://localhost:4200`).

3.  **Simulate Mobile View:**
    *   **Resize Window:** Slowly resize your browser window to a narrower width (e.g., less than 768px).
    *   **Developer Tools:** Open your browser's developer tools (usually F12 or right-click -> Inspect) and enable device mode (look for a phone/tablet icon). Select a mobile device preset.

4.  **Verify Functionality:**
    *   On small screens, the "Deck Builder", "Leaderboard", and "Suggestions" buttons should initially be hidden.
    *   A "hamburger" menu icon (three horizontal bars) should appear on the right side of the navbar.
    *   Click the hamburger menu icon. The navigation buttons should now appear, stacked vertically.
    *   Click the hamburger menu icon again. The navigation buttons should hide.
    *   Resize the window back to a larger (desktop) size. The hamburger menu should disappear, and the navigation buttons should revert to their original horizontal layout.
    *   The `navbar-title` (HSQuizz) should be hidden below 480px.
    *   The `btn-text` inside the nav buttons should be hidden below 480px, but visible when the menu is open.
